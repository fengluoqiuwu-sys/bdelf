# 调整：推理单前向 SC-CFG + 评测对齐论文采样

- **父分支**：`elf-cfg`
- **类型**：同分支 bugfix（非换向）
- **原因**：对照官方 `pytorch_elf` / JAX `sampling_utils._forward_sample_self_cond`，
  `num_self_cond_cfg_tokens > 0` 时推理应为 **单前向 + 传入 w**；旧实现做了
  inference-time 双前向外推，等于双重 guidance。在线 eval 还用 ODE/16、未强制 w=3，
  导致 gen_ppl 假低、无法监控 collapse。

## 改动

1. `models/elf/model.py`：training-time SC-CFG 路径改为单前向；无 scale token 时才外推，且同时导 v/x。
2. `train/eval.py`：ELF gen-eval → SDE/32 + logit_normal + `self_cond_cfg_scale=3`；返回 uniq_mean / nonempty_frac。
3. `train/metrics.py` + `train.py`：eval_log 增加 `gen_uniq_mean`, `gen_nonempty_frac`。
4. `config/models/elf/100m.yaml`：去掉重复字段块；`_doc` 标明 SC-CFG。
5. `FL_ELFSamplingConfig.self_cond_cfg_scale` 默认 3.0。
